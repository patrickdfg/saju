# 온도 v2 · 사주·타로·오늘의 인상

한국어 모바일 웹앱. API 키와 서버 없이 작동하는 정적 HTML/CSS/JavaScript 앱입니다.

## 바로 실행

저장소를 내려받고 다음을 실행한 뒤 http://localhost:8000 접속:

```sh
python -m http.server 8000
```

이미 빌드한 로컬 라이브러리와 카드 데이터를 포함하므로 앱 실행에 npm 설치는 필요 없습니다. GitHub Pages에서는 main 브랜치 루트를 게시하면 됩니다.

## 통합 기능

- 사주: 양력·한국 음력·윤달, 절기 기준 사주팔자, 시간 미상, 자시 3가지 기준, 도시별 진태양시 선택
- 상세표: 십신·지장간·십이운성, 오행·음양 개수, 일부 합충·공망, 선택적 대운, 연도별 연주와 절기별 월주
- 타로: 78장 정·역방향, 1·3·5·10장 배열, 하루 고정 카드, 자리별 질문과 종합 키워드
- 카드 도감: 전체 78장 검색, 메이저/마이너·슈트 필터, 정·역방향 뜻
- 관상·인상: 사진을 로컬 거울로 사용하고 직접 선택한 분위기의 표현 팁과 무작위 응원 메시지 제공. 얼굴에서 성격·운명을 추론하지 않음
- 기록: 기존 v1 기록 유지, 결과 저장, 감사 메모, 삭제, 사주·타로 결과 텍스트 다운로드
- 결과 끝에 감사·소망·평안·기도를 담은 짧은 문장. 별도 종교 메뉴 없음

## 출처·한계

[SOURCES.md](SOURCES.md)에 실제 검토한 프로젝트, 채택 여부, MIT 고지, 계산 기준, 검증 범위를 기록했습니다. GitHub 전체를 빠짐없이 수집한 것은 아닙니다.

사주 계산은 yhj1024/manseryeok와 golbin/ssaju 표를 통합했습니다. 한국 출생, 양력 환산 1908~2049년 범위를 지원합니다. 전통 규칙/학파에 따라 결과가 다르며 전문 감정이나 과학적 성격 진단이 아닙니다.

타로 카드 메타데이터는 Tarotoo(MIT), 한국어 해석은 온도용으로 작성·각색했습니다. 사전 문구를 조합하며 사용자의 자유 질문을 이해하는 AI 상담은 아닙니다. 유료 외부 API를 쓰지 않습니다.

입력·사진은 서버에 전송하지 않습니다. 결과 저장은 브라우저 localStorage만 사용하고 사진은 포함하지 않습니다. 다른 기기와 동기화되지 않으며, 기록은 최대 50개입니다.

## 개발·검증

```sh
npm install
npm run build
npm test
```

- `vendor-src/`: MIT 원본 계산 소스 및 추출한 표
- `tools/build.cjs`: 브라우저용 엔진·카드 데이터 재생성
- `data/tarotoo-original.json`: MIT 원본 데이터
- `data/tarot-ko.tsv`: 카드 순서에 대응하는 한국어 해석
- `app.js`: 공통 화면·기록 / `saju.js`: 만세력 UI / `tarot.js`: 카드 UI / `face.js`: 사진 거울
- `tests/check.cjs`: jsdom 기능 검증. 실제 기기 화면의 시각적 검증은 별도 필요
