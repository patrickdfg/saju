# 온도 v2 · 사주·타로·오늘의 인상

한국어 모바일 웹앱. 기본 기능은 API 키와 서버 없이 작동하는 정적 HTML/CSS/JavaScript 앱입니다.

## 바로 실행

저장소를 내려받고 다음을 실행한 뒤 http://localhost:8000 접속:

```sh
python -m http.server 8000
```

이미 빌드한 로컬 라이브러리와 카드 데이터를 포함하므로 앱 실행에 npm 설치는 필요 없습니다. GitHub Pages에서는 main 브랜치 루트를 게시하면 됩니다.

## 통합 기능

- 사주: 양력·한국 음력·윤달, 절기 기준 사주팔자, 시간 미상, 자시 3가지 기준, 도시별 진태양시 선택
- 상세표: 십신·지장간·십이운성, 오행·음양 개수, 일부 합충·공망, 선택적 대운, 연도별 연주와 절기별 월주
- 타로: 78장 정·역방향, 1·3·5·10장 배열, 하루 고정 카드, 자리별 질문과 종합 키워드
- 카드 도감: 전체 78장 검색, 메이저/마이너·슈트 필터, 정·역방향 뜻
- 관상·인상: 사진을 로컬 거울로 사용하고 직접 선택한 분위기의 표현 팁과 무작위 응원 메시지 제공. 얼굴에서 성격·운명을 추론하지 않음
- 기록: 기존 v1 기록 유지, 결과 저장, 감사 메모, 삭제, 사주·타로 결과 텍스트 다운로드
- 결과 끝에 감사·소망·평안·기도를 담은 짧은 문장. 별도 종교 메뉴 없음

## 출처·한계

[SOURCES.md](SOURCES.md)에 실제 검토한 프로젝트, 채택 여부, MIT 고지, 계산 기준, 검증 범위를 기록했습니다. GitHub 전체를 빠짐없이 수집한 것은 아닙니다.

사주 계산은 yhj1024/manseryeok와 golbin/ssaju 표를 통합했습니다. 한국 출생, 양력 환산 1908~2049년 범위를 지원합니다. 전통 규칙/학파에 따라 결과가 다르며 전문 감정이나 과학적 성격 진단이 아닙니다.

타로 카드 메타데이터는 Tarotoo(MIT), 한국어 해석은 온도용으로 작성·각색했습니다. 사전 문구를 조합하며 사용자의 자유 질문을 이해하는 AI 상담은 아닙니다. 유료 외부 API를 쓰지 않습니다.

입력·사진은 서버에 전송하지 않습니다. 결과 저장은 브라우저 localStorage만 사용하고 사진은 포함하지 않습니다. 다른 기기와 동기화되지 않으며, 기록은 최대 50개입니다.

## 개발·검증

```sh
npm install
npm run build
npm test
```

- `vendor-src/`: MIT 원본 계산 소스 및 추출한 표
- `tools/build.cjs`: 브라우저용 엔진·카드 데이터 재생성
- `data/tarotoo-original.json`: MIT 원본 데이터
- `data/tarot-ko.tsv`: 카드 순서에 대응하는 한국어 해석
- `app.js`: 공통 화면·기록 / `saju.js`: 만세력 UI / `tarot.js`: 카드 UI / `face.js`: 사진 거울
- `tests/check.cjs`: jsdom 기능 검증. 실제 기기 화면의 시각적 검증은 별도 필요

카드 디자인: RWS 원화 78장, 금빛 프레임·장식 뒷면, 결과 카드 확대, 모바일 큰 그림 보기. 이미지 출처는 SOURCES.md 참고.

관상 사진: 「사진 촬영」은 휴대폰 전면 카메라를 요청하고, 「앨범에서 선택」은 기존 사진을 불러옵니다. 촬영 동작은 브라우저 지원에 따라 사진 선택창으로 대체될 수 있습니다. 두 경로 모두 기기 내 미리보기만 하며 서버에 전송하지 않습니다.

매일 사주: 생년월일·출생시간·음력/윤달·출생지·계산 기준을 브라우저에 저장하며 수정/삭제할 수 있습니다. 앱 방문/화면 복귀 시 한국 날짜 기준 일진과 출생 일간의 십신 관계로 오늘의 성찰 풀이를 갱신합니다. 정오 기준 일진이며 푸시 알림이나 백그라운드 예약 발송은 아닙니다. 같은 날의 풀이와 마무리 문장은 일정하게 유지됩니다.

별자리·점성술: Astronomy Engine의 태양·달·8행성 위치, 열대황도 원형 차트, 주요 각도, 달 위상, 12별자리 도감, 한국어 성찰 풀이. 사주 저장 생일(음력/윤달 포함)을 불러오고 별자리 생일을 별도 저장할 수 있습니다. 출생시간 미상은 정오 추정과 후보 범위로 표시합니다. 한국 출생기록만 지원하며 상승궁·하우스는 제외합니다. 상세 비교·버전·라이선스는 SOURCES.md를 참고하세요.

쉬운 사주 화면: 자연에 빗댄 한눈 요약, 강점과 균형 제안, 관계·일·생활 풀이, 쉬운 오행 그림을 먼저 제공합니다. 한자·십신·대운 등 기존 계산표는 「상세 만세력」에 접어 보관하며 저장·다운로드에도 쉬운 풀이를 포함합니다. 오늘의 풀이도 실천과 돌아볼 점을 먼저 보여줍니다.


## Gemini 상세 만세력 해설
- 사주 결과 아래 Gemini 영역에서 본인 API 키와 사용 가능한 모델 ID를 입력합니다. 전송 정보를 확인하고 버튼을 눌러야 호출됩니다. 자동 호출/재시도 없음.
- 기본 모델 ID는 공식 generateContent 문서의 `gemini-3.8-flash` 예시 기준(2026-10-12). 계정별 이용 가능 여부에 따라 변경할 수 있습니다.
- 개인 BYOK 시험 사용 방식입니다. API 키를 소스/로컬스토리지/세션스토리지/기록/URL에 넣지 않습니다. 현재 페이지의 비밀번호 입력칸에만 두며 페이지 종료 시 지웁니다. 브라우저 확장 등으로부터 키를 완전히 보호하는 서버 보관 방식은 아닙니다.
- 운영자 공용 키를 넣어 공개 서비스로 제공하려면 별도 인증·사용량 제한을 갖춘 서버 프록시가 필요합니다. GitHub Pages에 공용 키를 하드코딩하지 마세요.
- Google에 보내는 데이터: 기둥·십신·오행·지장간·합충·공망·대운·계산상 유의사항. 생년월일 원문·이름·사진·개인 기록은 제외하지만 사주 데이터도 개인 관련 정보입니다.
- 요금/데이터 처리는 Google API 계정·이용 조건에 따릅니다. 기본 기능의 로컬 처리 안내와 구분했습니다.
- 제한: API 키가 제공되지 않아 유료/실제 모델 호출은 수행하지 않았습니다. 응답·실패·취소·정보 최소화·출력 escaping은 모의 응답으로 검증합니다.
- REST: https://ai.google.dev/api/generate-content / API 키 안내: https://ai.google.dev/gemini-api/docs/api-key

Gemini 보고서는 내가 아는 내 모습 / 남이 보는 내 모습 / 재능과 적성 / 재물 / 애정 / 일복 / 인복 / 관운 / 길성과 신살의 9개 장으로 생성합니다. JSON 구조와 모든 항목을 검증하며 선택한 신살 3종(천을귀인·도화살·화개살)은 일치 위치를 직접 계산해 전달합니다.
