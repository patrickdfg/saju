# 온도 · 타로와 사주

모바일에 맞춘 한국어 타로·사주 웹앱. 종교 메뉴 없이 결과 끝에 감사·소망·평안·기도를 담은 짧은 성찰 문장을 넣었습니다.

## 실행

별도 설치나 API 키 없이 `index.html`을 엽니다. 안정적인 브라우저 저장을 위해 정적 웹 서버 사용을 권합니다.

```sh
python -m http.server 8000
```

브라우저에서 http://localhost:8000 접속.

## 기능

- 메이저 아르카나 22장, 중복 없는 무작위 덱에서 직접 3장 선택
- 오늘의 마음 / 사랑과 관계 / 일과 배움 / 돈과 생활 주제
- 양력 생년월일과 한국 표준시 기반 연·월·일·시주 계산
- 오행 대표 개수와 자체 작성 성찰 해석
- 출생시간 미상 지원(시주 제외)
- 결과 최대 50개, 감사 메모 저장·수정·삭제
- 서버 전송 없는 브라우저 로컬 저장. 다른 기기와 동기화되지 않습니다.

## 계산 기준과 한계

계산 엔진은 함께 포함한 `vendor/lunar.js` (6tail/lunar-javascript, MIT License)입니다. 연·월주는 절기로 구분하며, 라이브러리의 UTC+8 절기 시각에 맞춰 KST 입력에서 1시간을 빼서 해당 주를 구합니다. 일주는 자정 교체 기준(sect 2)입니다. 시주는 같은 날의 일간과 2시간 지지 구간으로 계산합니다. 23~24시는 자정 일주 규칙으로 현재 날짜의 일간을 사용합니다. 지역별 진태양시, 음력 입력, 대운·세운·용신·지장간·강약 분석은 지원하지 않습니다. 시간 미상은 정오 기준이라 절기 당일의 연·월주가 실제 출생시각에 따라 달라질 수 있습니다. 해외 출생에는 적합하지 않습니다.

오행 막대는 천간·지지의 대표 오행 개수이며 점수나 기운의 강약이 아닙니다. 해석은 미리 작성한 문구 조합이며 AI 상담 또는 전문 감정이 아닙니다. 미래의 사건·건강·금전 성과·신의 뜻을 단정하지 않습니다.

## 파일

- `index.html`: 화면 구조
- `style.css`: 반응형 디자인
- `app.js`: 타로 데이터, 사주 계산, 로컬 기록
- `vendor/lunar.js`, `vendor/LICENSE-lunar.txt`: 계산 라이브러리와 라이선스
